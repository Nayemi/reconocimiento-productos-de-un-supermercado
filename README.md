# reconocimiento-productos-de-un-supermercado
Detectar productos en el gancho mediante redes YOLO, las que identifican marcas en fotografías de estantes o las que reconocen artículos en tiempo vivo desde un celular. Incluso hay trabajos de otros lugares, como la clasificación de fruta por lo podrido o no que muestran hasta donde llegan estas técnicas cuando el entorno es controlado.
